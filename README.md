# 簡単に日本語を学ぶ — learn japanese easy

An ebook app by **EX Inc.** for Windows 10/11 (x64). Everything works offline.

## The book
- **Page-turn reader.** Pages turn with an animation. Use the ‹ › arrows, the ← → / PgUp / PgDn / Space keys, the mouse wheel, or drag to swipe. You also get a Contents list, bookmarks (B) and zoom (+ / − / 0, Ctrl+wheel, drag to pan).
- **Front cover.** It is also the Press Start screen, shown next to the back cover.
- **Kanji & kana art page.** The original grey page is kept as a decorative page. Right after it come two correct reference pages in the same grey vertical style:
  - the gojūon (hiragana, with katakana and romaji)
  - 24 beginner kanji with kun/ON readings and meanings, plus 日本・日本語・学生・先生・大学
- **Hiragana and Katakana charts** with romaji.
- **40 words in the page-3 style:** greetings, numbers 1–10, food and family. Each word has furigana, an orange kana line with romaji, and English.
- **3 tap-to-answer quizzes:** hiragana, katakana and words.
- **My Pages** (your own pages), then the back cover.
- **Tap to hear.** Tap any word or character. The book has built-in Japanese audio, pre-generated offline with Open JTalk. For your own sentences it uses an installed Windows Japanese voice (SAPI5 / OneCore) if there is one.

## Page Maker
- **English → 日本語, offline.** It uses a curated phrase book plus simple sentence patterns (I love X, where is X, this is X …).
- **Furigana and Hepburn romaji are made automatically.** Curated readings come first, then the offline kakasi dictionary. Every field can be edited.
- **Ink brush.** Speed-thinned strokes with tapered ends. Colours: ochre, brown, black, red, or a colour wheel with brightness. You can set the size, and there is an eraser, Undo (Ctrl+Z) and Clear.
- **Save and export.** Save to **My Pages** inside the book. Export a page as PNG, or this page / all My Pages as one PDF.

## Install
Run `learn.japanese.easy.Setup.1.0.0.exe`. It installs for the current user only (no admin, no UAC). Or unzip `learn.japanese.easy.1.0.0.Windows.x64.zip` and run `learn japanese easy.exe`.
